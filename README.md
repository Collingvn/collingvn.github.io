# Collin Gavin — personal site

A single-page personal website built with static HTML and CSS.

## Content decisions

- **Audience:** classmates, hiring teams, and people searching for Collin Gavin.
- **Three things to communicate:** computer science studies at Monmouth University; QA and technical support experience plus the PantryPal project; interest in QA and cybersecurity.
- **Left off deliberately:** home address, phone number, class schedule, private contact details, and information about other people.
- **Stranger check:** Anyone can find a public GitHub page, including prospective employers. The page uses only information intended for public viewing.

## Preview

Open `dist/index.html` in a browser. GitHub Pages can publish from the `dist` folder through a GitHub Actions workflow or from a root-level copy of `index.html`.
